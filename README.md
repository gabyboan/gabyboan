# Hola, soy Gabriel Boan

Estoy construyendo un ecosistema de aplicaciones conectadas a Supabase para
digitalizar procesos administrativos, gestionar personal y automatizar flujos
internos en un entorno hospitalario.

Soy estudiante de la Licenciatura en Sistemas de Informacion en UADER, sede Oro
Verde, Facultad de Ciencia y Tecnologia (FCyT).

Trabajo principalmente con Next.js, React, TypeScript, Supabase, Cloudflare
Workers, Android, n8n y automatizaciones con IA.

## Proyecto principal

Actualmente desarrollo un conjunto de herramientas integradas de comunicacion y
gestion interna hospitalaria:

- Aplicacion Android para propuestas de suplencias, con acceso por roles. Cada
  jefe puede ver y cargar suplentes segun su area, consultar sus suplencias
  cargadas, y un administrador puede gestionar todas las suplencias.
- Modulo de gestion RRHH para carga de francos y horas por enfermedad,
  particulares u oficiales, con reglas especificas de validacion y calculo.
- Portal de comunicacion interna hospitalaria, construido con Cloudflare
  Workers, validacion CAPTCHA y despliegue automatico desde GitHub.
- Legajo Digital, una aplicacion para crear, editar e inactivar personas por
  fallecimiento, jubilacion, renuncia u otros motivos administrativos.

## Proximos modulos

El objetivo es ampliar el sistema con:

- Gestion de imprevistos.
- Solicitud de medicos con chatbot integrado.
- Automatizaciones con n8n, ChatGPT y WhatsApp.
- Generacion de QR para completar datos de agentes en puntos fisicos.
- Control de asistencia vinculado a reloj biometrico ZKTeco.
- Banco de datos para certificaciones de suplencias.
- Evaluacion automatica de cortes en suplencias cuando existen dias
  discontinuos.
